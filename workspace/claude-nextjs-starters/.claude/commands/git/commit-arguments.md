아래 인자를 파싱하세요:
$ARGUMENTS

## 1단계: 인자 파싱

- **COMMIT_MSG**: 첫 번째 따옴표(큰따옴표 또는 작은따옴표) 안의 텍스트. 따옴표가 없으면 전체 $ARGUMENTS를 커밋 메시지로 사용
- **TASKS**: 따옴표 이후 공백으로 구분된 단어 목록 (없을 수도 있음)

## 2단계: 분기 처리

### TASKS가 없는 경우
현재 변경사항을 분석하고 COMMIT_MSG로 커밋을 생성하세요.

### TASKS가 있는 경우

각 작업을 **순서대로** 검증하세요. 앞 작업이 성공해야 다음 작업 검증을 진행합니다.

작업 이름을 보고 적절한 검증 방법을 판단하세요:
- 빌드 관련 → `npm run build`
- 타입 관련 → `npx tsc --noEmit`
- 린트 관련 → `npm run lint`
- 테스트 관련 → `npm run test`
- 기타 → git diff, 파일 변경 상태, 코드 분석으로 판단

검증이 끝나면 결과에 따라 아래 중 하나로 처리하세요:

**모두 성공 시:**
각 작업의 성공 여부를 ✅로 표시한 후,
"모든 작업 검증 완료. 커밋 및 푸시를 진행합니다." 라고 안내하고
COMMIT_MSG로 커밋 후 `git push`를 수행하세요.

**하나라도 실패 시:**
각 작업의 결과를 ✅/❌로 표시하고 실패 이유를 기재한 후,
"커밋 및 푸시가 취소되었습니다. 검증에 실패한 작업을 수정한 후 다시 시도하세요." 라고 안내하세요.
커밋과 푸시는 수행하지 마세요.
