## 사용법 

1. /git diff $1 $2
2. /git diff $1 
3. /git diff 
4. /git diff $1 $2 -- $3

## 프로세스

1. 사용법 1
   - $1 : 비교 주체가 되는 git log 
   - $2 : 비교 대상이 되는 git log 
2. 사용법 2
   - $1 : 비교 대상이 되는 git log 
3. 사용법 3
   - 인자가 없을경우 현재 head와 직전 commit 비교 
4. 사용법 4
   - $1 : 비교 주체가 되는 git log 
   - $2 : 비교 대상이 되는 git log 
   - $3 : 비교 대상이 되는 파일 

## 참고사항

1. 일치하지 않는 코드를 코드 비교창에서 보여줍니다.
2. 커밋 로그의 비교의 경우 코드 차이가있는 파일들이 코드 비교창에 탭으로 보여집니다.
