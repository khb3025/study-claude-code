# 관리자 사용 가이드

노션 기반 견적서 관리 시스템의 관리자 기능 사용법을 안내합니다. 별도의 회원가입 없이 환경변수로 설정한 단일 관리자 비밀번호로 로그인합니다.

## 로그인

1. `/admin` 또는 보호된 관리자 경로(`/admin/invoices` 등)에 접속하면 세션이 없을 경우 자동으로 `/admin/login`으로 이동합니다.
2. `.env.local`의 `ADMIN_PASSWORD` 값을 입력해 로그인합니다.
3. 로그인에 성공하면 HMAC-SHA256으로 서명된 stateless 세션 토큰이 `httpOnly` 쿠키(`admin_session`)로 발급되며, 7일간 유지됩니다.
4. 세션 쿠키는 `sameSite=strict`로 설정되어 있어 다른 사이트에서의 요청 위조(CSRF)에 노출되지 않습니다. 운영 환경(`NODE_ENV=production`)에서는 `secure` 속성도 함께 적용되어 HTTPS에서만 전송됩니다.

## 견적서 목록 (`/admin/invoices`)

- Notion 데이터베이스에 등록된 모든 견적서가 10건 단위로 페이지네이션되어 표시됩니다.
- 각 컬럼 헤더(견적서 번호/클라이언트명/발행일/유효기간/상태/총 금액)를 클릭하면 해당 기준으로 정렬됩니다.
- 검색창에 클라이언트명 또는 견적서 번호를 입력하면 URL 쿼리 파라미터(`?search=`)로 반영되어 필터링됩니다.
- 상태(대기/승인/거절)와 발행일 범위로도 필터링할 수 있습니다(`?status=`, `?dateFrom=`, `?dateTo=`).
- 필터/정렬/페이지 상태는 모두 URL에 담기므로 링크를 공유하거나 새로고침해도 동일한 화면을 다시 볼 수 있습니다.

## 링크 복사 및 공유

각 견적서 행의 "링크" 컬럼에서 다음 작업이 가능합니다.

- **링크 열기**: 고유 조회 URL(`/invoice/[notionPageId]`)로 바로 이동합니다.
- **링크 복사**: 클립보드에 전체 URL을 복사하고 토스트로 성공 여부를 알려줍니다.
- **이메일로 공유**: 기본 메일 클라이언트에서 견적서 번호와 링크가 채워진 메일 작성 화면을 엽니다(`mailto:`).

카카오톡/텔레그램 공유 및 링크 조회수 통계는 MVP 범위에서 의도적으로 제외되어 있습니다(추후 별도 요청 시 구현).

## 로그아웃

관리자 네비게이션의 "로그아웃" 버튼을 누르면 세션 쿠키가 즉시 삭제되고 로그인 페이지로 이동합니다.

## 다크모드

관리자 네비게이션의 테마 전환 버튼으로 라이트/다크 모드를 전환할 수 있습니다. 선택한 테마는 `next-themes`가 `localStorage`에 저장하므로 새로고침 후에도 유지됩니다.

## 데이터 소스에 대한 주의사항

- 견적서 데이터는 이 앱이 아니라 **Notion 데이터베이스에서 직접** 관리합니다. 항목 추가/수정/삭제는 Notion에서 수행하세요.
- Notion API 호출 결과는 속도 제한 대응을 위해 60초간 캐싱됩니다(`src/lib/notion.ts`). Notion에서 데이터를 수정한 직후에는 최대 60초까지 목록/상세 화면에 반영이 지연될 수 있습니다.
