# 노션 견적서 웹 열람 서비스 MVP PRD

## 🎯 핵심 정보

**목적**: 노션(Notion)에 담당자가 작성한 견적서를 클라이언트가 별도 툴 설치 없이 웹에서 확인하고 PDF로 다운로드할 수 있게 한다.
**사용자**: 견적서를 노션 데이터베이스로 관리하는 프리랜서/소규모 에이전시로부터 견적서를 받는 외부 클라이언트(고객사 담당자).

## 🚶 사용자 여정

```

1. [클라이언트가 이메일로 받은 견적서 링크 클릭] 또는 [홈페이지 방문 후 "견적서 조회하기" 클릭]
   ↓

2. 견적서 인증 페이지 (이메일 확인)
   ↓ [이메일 주소 입력 후 확인 버튼 클릭]

   [이메일 일치 & 링크 유효] → 견적서 상세 페이지로 자동 리디렉션
   [이메일 불일치 / 링크 만료 / 존재하지 않는 견적서] → 접근 오류 페이지로 이동
   ↓

3. 견적서 상세 페이지
   ↓ [내용 확인 후 PDF 다운로드 버튼 클릭]

4. PDF 파일 다운로드 완료 → 견적서 상세 페이지에 그대로 머무름 (재열람/재다운로드 가능)
   ↓ [접근 종료]

5. 세션 종료(로그아웃) → 홈페이지로 리디렉션

```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 견적서 상세 조회 | 공급자/수신자 정보, 품목별 상세(품목명·수량·단가·금액), 합계금액, 유효기간, 상태를 웹 화면에 표시 | 서비스의 핵심 가치인 "웹 열람" 자체 | 견적서 상세 페이지 |
| **F002** | 견적서 PDF 다운로드 | 현재 조회 중인 견적서를 PDF 파일로 즉시 생성하여 다운로드 | 서비스의 핵심 가치인 "PDF 다운로드" 자체 | 견적서 상세 페이지 |
| **F003** | 노션 데이터 연동 조회 | 노션 API를 통해 담당자가 입력한 견적서 원본 데이터를 읽어와 화면에 반영 (읽기 전용, 쓰기 없음) | 노션이 CMS 역할을 하는 이 서비스의 데이터 파이프라인 핵심 | 견적서 상세 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F010** | 기본 인증 (이메일 접근 인증) | 회원가입 없이, 발급된 고유 링크 접속 후 이메일 주소를 입력해 본인 확인 → 접근 세션 발급/종료 | 견적서는 개인정보이므로 최소한의 본인 확인이 필요 | 홈페이지, 견적서 인증 페이지 |
| **F011** | 접근 링크 유효성 검증 | 링크 토큰 만료, 이메일 불일치, 존재하지 않는 견적서 여부를 확인하고 결과에 따라 안내 | 잘못된/만료된 접근을 차단하는 최소 보안 장치 | 견적서 인증 페이지, 접근 오류 페이지 |
| **F012** | 열람 기록 최소 저장 | 최초 열람 시각·PDF 다운로드 시각을 기록해 상태를 갱신 (담당자가 노션에서 참고 가능한 최소 데이터) | 클라이언트가 견적서를 확인했는지 담당자가 파악할 수 있는 최소 지원 기능 | 견적서 상세 페이지 |

### 3. MVP 이후 기능 (제외)

- 담당자용 별도 관리 화면 (견적서 작성/편집은 노션에서만 수행)
- 견적서 전자 서명/승인 기능
- 견적서 히스토리 및 버전 관리
- 다국어 지원
- 이메일 자동 재발송/알림 기능
- 온라인 결제 연동
- PDF 템플릿 커스터마이징(디자인 선택)
- 견적서 검색/필터링
- 클라이언트 코멘트/피드백 기능

| **사용자 행동** | 서비스 안내 확인 후 "견적서 조회하기" 버튼 클릭 |
| **주요 기능** | • 서비스 소개 문구 표시<br>• **견적서 조회하기** 버튼 (견적서 인증 페이지로 이동) |
| **다음 이동** | 버튼 클릭 → 견적서 인증 페이지 |

### 견적서 인증 페이지

> **구현 기능:** `F010`, `F011` | **인증:** 링크 토큰 필요 (미인증 상태)

| 항목 | 내용 |
|------|------|
| **역할** | 이메일 기반 본인 확인 전용 페이지 |
| **진입 경로** | 클라이언트가 수신한 견적서 고유 링크 클릭, 또는 홈페이지에서 "견적서 조회하기" 클릭 |

| **주요 기능** | • 링크 토큰 자동 검증<br>• 이메일 입력 폼 및 형식 검사<br>• 노션에 등록된 수신자 이메일과 일치 여부 확인<br>• **확인** 버튼 |
| **다음 이동** | 인증 성공 → 견적서 상세 페이지(자동 리디렉션), 인증 실패 → 접근 오류 페이지 |

> **구현 기능:** `F001`, `F002`, `F003`, `F012` | **인증:** 인증 완료 세션 필요

| 항목 | 내용 |
|------|------|
| **역할** | 견적서 내용을 확인하고 PDF로 내려받는 핵심 페이지 |
| **진입 경로** | 견적서 인증 페이지에서 이메일 인증 성공 시 자동 리디렉션 |

| **다음 이동** | PDF 다운로드 → 같은 페이지 유지, 접근 종료 → 홈페이지 |

## 🗄️ 데이터 모델

### Quote (견적서 - 노션 원본 캐시)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| notionPageId | 노션 원본 페이지 ID | String |
| quoteNumber | 견적서 번호 | String |
| clientEmail | 수신자 이메일 (인증 기준) | String |
| clientName | 수신자(클라이언트)명 | String |
| supplierName | 공급자명 | String |
| status | 상태 (발송/열람함/만료) | String |
| validUntil | 유효기간 | Date |
| totalAmount | 합계 금액 | Number |

### QuoteItem (견적서 품목)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| quoteId | 소속 견적서 | → Quote.id |
| itemName | 품목명 | String |
| quantity | 수량 | Number |
| unitPrice | 단가 | Number |
| amount | 항목 금액 | Number |

### AccessToken (접근 인증 토큰)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| quoteId | 대상 견적서 | → Quote.id |
| tokenHash | 링크 토큰 해시값 | String |
| verifiedEmail | 인증 완료된 이메일 | String |
| verifiedAt | 인증 완료 시각 | Timestamp |
| expiresAt | 토큰 만료 시각 | Timestamp |

### ViewLog (열람/다운로드 기록)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| quoteId | 대상 견적서 | → Quote.id |
| viewedAt | 최초 열람 시각 | Timestamp |
| pdfDownloadedAt | PDF 다운로드 시각 (nullable) | Timestamp |

## 🛠️ 기술 스택 (최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 15** (App Router) - React 풀스택 프레임워크
- **TypeScript 5.6+** - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 🎨 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** - 고품질 React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리

### 📝 폼 & 검증

- **React Hook Form 7.x** - 폼 상태 관리 (이메일 인증 입력)
- **Zod** - 스키마 검증 라이브러리

### 🗄️ 백엔드 & 데이터베이스

- **Supabase** - BaaS (접근 세션·열람 기록 저장, PostgreSQL 기반)
- **PostgreSQL** - 관계형 데이터베이스 (Supabase 포함)

### 🔗 외부 연동

- **@notionhq/client** (Notion API 공식 SDK) - 견적서 원본 데이터 읽기 전용 조회

### 📄 PDF 생성

- **@react-pdf/renderer** - React 컴포넌트 기반 서버 사이드 PDF 생성

### 🚀 배포 & 호스팅

- **Vercel** - Next.js 15 최적화 배포 플랫폼

### 📦 패키지 관리

- **npm** - 의존성 관리
